# MExpense

A simple and clean personal expense tracking app built with Flutter.
Developed as part of the App Development Boot-Camp (May 2026).

## Features

- User authentication (Sign up, Login, Forgot Password)
- Track daily expenses by category
- Monthly expense summary with chart
- Transaction history with search and filter
- Budget setting and currency preference

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Provider
- **Backend:** Firebase / REST API

### Prerequisites

- Flutter SDK 3.41.6
- Dart SDK 3.11.4
- Android Studio / VS Code
